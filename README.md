# אבחון רמת AI · מרכז הרכב שמעון ברזילי

דף נחיתה בעיצוב בהיר, טיפוגרפי וקינטי (בהשראת cuberto.com), עם **Scrollytelling**, סמן מותאם וכפתורים מגנטיים — ומבדק מקדים מדיד, לפני מיני-קורס על שימוש בכלי בינה מלאכותית בעבודה.

המבדק מודד ארבעה מדדים — **ידע, ניסיון, צרכים ומוכנות** — כולל **שאלות ידע מדורגות (בסיסי → בינוני → מתקדם)** וצ׳קליסט יכולות אמיתי, ובסוף מפיק לכל עובד **ציון "מדד מוכנות AI" (0–100)**, **רמה (1–5)**, **פירוט ידע** ו**מזהה אבחון** לשמירה. זהו **קו בסיס** שאפשר להריץ שוב בסוף הקורס ולהשוות כמה כל עובד עלה.

## מה יש כאן
- `index.html` — הדף כולו בקובץ אחד (HTML + CSS + JavaScript). אין תלות בשרת או בבנייה.
- `assets/logo.png` — הלוגו של מרכז הרכב.
- `assets/mascot.png` — דמות המותג ("תו תקן"), עם רקע שקוף.
- `assets/stamp.svg` — קובץ המקור של הדמות.
- `apps-script/Code.gs` — סקריפט האיסוף לגיליון המשוב בדרייב.
- `SETUP-DRIVE.md` — מדריך חיבור הדף לגיליון המשוב (הקמה של דקה).

## הפעלה
פותחים את `index.html` בכל דפדפן. אפשר גם לפרסם כאתר סטטי (GitHub Pages, Netlify, Vercel) — צריך רק להעלות את `index.html` יחד עם תיקיית `assets/`.

## איסוף כל התשובות במקום אחד (Drive)
היעד: כל אבחון שמושלם נשמר **אוטומטית כשורה** בגיליון המשוב שבתיקיית הדרייב, כדי להסיק מסקנות על תכני הקורס.

הדף שולח כל תוצאה ל-**Google Apps Script Web App** שמוסיף אותה לגיליון. ההקמה החד-פעמית (דקה) מתוארת ב-[`SETUP-DRIVE.md`](SETUP-DRIVE.md): מדביקים את `apps-script/Code.gs` בגיליון, מפרסמים כ-Web App, ומדביקים את הכתובת ב-`index.html`:
```js
const SUBMIT_URL = "https://script.google.com/macros/s/.../exec";
```
כל עוד `SUBMIT_URL` ריק — הדף עדיין עובד, ובסוף העובד יכול **לשלוח במייל / להעתיק / להוריד** את התוצאה (הכתובת ב-`OWNER_EMAIL`).

## התאמות אישיות
- **החלפת לוגו/דמות** — מחליפים את הקבצים בתיקיית `assets/` (באותם שמות), או מעדכנים את הנתיבים ב-`index.html`.
- **עריכת השאלות** — כל המבדק מוגדר במערך `QUESTIONS` בתוך `index.html`. נתמכים: טקסט, בחירה יחידה, בחירה מרובה, סליידר ודירוג כוכבים. שאלת ידע מסומנת ב-`knowledge:true` + `klevel` (`basic`/`inter`/`adv`), והתשובה הנכונה ב-`correct:true`.
- **הציון והרמות** — לוגיקת החישוב בפונקציות `computeIndex` / `knowledge`, ורמות התוצאה במערך `LEVELS`. מבנה השורה שנשלחת לגיליון נקבע ב-`buildRecord`.
- **צבעים** — כל הפלטה הבהירה מוגדרת כמשתני CSS ב-`:root` בראש קובץ ה-`<style>`.
