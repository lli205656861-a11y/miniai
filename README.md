# אבחון רמת AI · מרכז הרכב שמעון ברזילי

דף נחיתה בסגנון **חלל קריר וקולנועי (hi-tech)** עם **Scrollytelling** בהשראת סרטון המותג —
הדמות ("תו תקן") טסה במהירות האור דרך מנהרת אור, עוברת פורטל, ונוחתת בעיר עתידנית ניאונית —
ולאחריו מבדק אבחון דינמי מקדים לפני מיני-קורס על שימוש ב-AI בעבודה.

המבדק מודד ידע אמיתי (שאלות מדורגות בסיסי→מתקדם) לצד ניסיון, צרכים ומוכנות, ומפיק לכל עובד
**ציון "מדד מוכנות AI" (0–100)**, **רמה (1–5)**, פירוט ידע לפי דרגה, ו**מזהה אבחון** לשמירה —
**קו בסיס** שאפשר להריץ שוב בסוף הקורס ולהשוות כמה כל עובד עלה.

## מה יש כאן
- `index.html` — הדף כולו בקובץ אחד (HTML + CSS + JavaScript, ללא תלויות בנייה).
- `assets/logo.png`, `assets/mascot.png`, `assets/stamp.svg` — נכסי המותג.
- `apps-script/Code.gs` — הסקריפט שאוסף כל אבחון לגיליון המשוב בדרייב.
- `SETUP-DRIVE.md` — הוראות הקמה של דקה לחיבור לדרייב.

## הפעלה
פותחים את `index.html` בכל דפדפן, או מפרסמים כאתר סטטי (GitHub Pages / Netlify / Vercel)
יחד עם תיקיית `assets/`.

## איסוף התשובות לדרייב
כל אבחון שמושלם נשלח **אוטומטית כשורה** לגיליון **"משוב אבחון AI"** שבתיקיית הדרייב,
דרך Google Apps Script Web App. ההקמה (דקה) מתוארת ב-[`SETUP-DRIVE.md`](SETUP-DRIVE.md);
מגדירים את `SUBMIT_URL` בתוך `index.html`. גיבוי: שליחה במייל / העתקה / הורדה.

## התאמות אישיות
- **צבעים** — כל הפלטה הקרירה מוגדרת כמשתני CSS ב-`:root` (`--cyan`, `--purple`, `--red`, `--bg`…).
- **החלפת לוגו/דמות** — מחליפים את הקבצים ב-`assets/` (באותם שמות).
- **עריכת השאלות** — מערך `QUESTIONS` בתוך `index.html`. שאלת ידע מסומנת ב-`knowledge:true`,
  דרגה ב-`klevel` (`basic`/`inter`/`adv`), והתשובה הנכונה ב-`correct:true`.
- **הציון והרמות** — הלוגיקה ב-`computeIndex` / `knowledge`, והרמות במערך `LEVELS`.
- **ה-Scrollytelling** — אפקט מהירות-האור מצויר ב-Canvas (`makeWarp`) ומונע-גלילה ב-`jRender`.
- **תעודה + תיק עובד** — כל אבחון מפיק תעודה מעוצבת (Canvas) שנשמרת בתיק העובד בדרייב. התהליך המלא מתועד ב-`WORKFLOW.md`.
