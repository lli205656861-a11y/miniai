# אבחון רמת AI · מרכז הרכב שמעון ברזילי

דף נחיתה בסגנון **קונסולת אבחון כהה (hi-tech)** עם **Scrollytelling** ומבדק מקדים מדיד, לפני מיני-קורס על שימוש בכלי בינה מלאכותית בעבודה.

המבדק מודד ארבעה מדדים — **ידע, ניסיון, צרכים ומוכנות** — כולל כמה שאלות ידע קלות, ובסוף מפיק לכל עובד **ציון "מדד מוכנות AI" (0–100)**, **רמה (1–5)** ו**מזהה אבחון** לשמירה. זהו **קו בסיס** שאפשר להריץ שוב בסוף הקורס ולהשוות כמה כל עובד עלה. את התוצאה אפשר לשלוח אליך בלחיצה.

## מה יש כאן
- `index.html` — הדף כולו בקובץ אחד (HTML + CSS + JavaScript). אין תלות בשרת או בבנייה.
- `assets/logo.png` — הלוגו של מרכז הרכב.
- `assets/mascot.png` — דמות המותג ("תו תקן"), עם רקע שקוף.
- `assets/stamp.svg` — קובץ המקור של הדמות.

## הפעלה
פשוט פותחים את `index.html` בכל דפדפן. אפשר גם לפרסם אותו כאתר סטטי (GitHub Pages, Netlify, Vercel וכו') — צריך רק להעלות את `index.html` יחד עם תיקיית `assets/`.

## איך אוספים את התשובות
בסיום השאלון העובד מקבל שלוש אפשרויות:
1. **שליחת התשובות** — נפתח מייל מוכן עם כל התשובות והפרופיל, לכתובת שמוגדרת בקוד.
2. **העתקת סיכום** — כל התשובות מועתקות ללוח.
3. **הורדה כקובץ** — קובץ טקסט עם הסיכום.

הכתובת שאליה נשלח המייל מוגדרת בראש בלוק ה-JavaScript ב-`index.html`:
```js
const OWNER_EMAIL = "lli205656861@gmail.com";
```
בהמשך אפשר בקלות לחבר את השאלון גם ל-Google Sheets / Forms או לשירות טפסים חיצוני.

## התאמות אישיות
- **החלפת לוגו/דמות** — מחליפים את הקבצים בתיקיית `assets/` (באותם שמות), או מעדכנים את הנתיבים ב-`index.html`.
- **עריכת השאלות** — כל המבדק מוגדר במערך `QUESTIONS` בתוך `index.html`. אפשר להוסיף, למחוק ולערוך שאלות בקלות. נתמכים סוגי שאלות: טקסט, בחירה יחידה, בחירה מרובה, סרגל (סליידר) ודירוג כוכבים. שאלת ידע מסומנת ב-`knowledge:true`, והתשובה הנכונה ב-`correct:true`.
- **הציון והרמות** — לוגיקת חישוב מדד המוכנות נמצאת בפונקציות `computeIndex` / `knowledgeScore`, ורמות התוצאה (השמות וההמלצות) במערך `LEVELS`.
- **צבעים** — כל הפלטה הכהה מוגדרת כמשתני CSS ב-`:root` בראש קובץ ה-`<style>`.
